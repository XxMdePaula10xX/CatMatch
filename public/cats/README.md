# 🖼️ Arte dos gatos (PNGs)

Coloque aqui as imagens finais dos gatinhos. O jogo usa **exatamente** estes
nomes de arquivo. Enquanto o arquivo não existe, o jogo mostra o emoji como
reserva — então pode adicionar um de cada vez sem quebrar nada.

## Gatos básicos
| Arquivo | Gato |
|---|---|
| `orange.png` | Gato Laranja (Alegre) |
| `gray.png` | Gato Cinza (Esperto) |
| `white.png` | Gato Branco (Mágico) |
| `black.png` | Gato Preto (Sortudo) |
| `siamese.png` | Gato Siamês (Charmoso) |
| `tabby.png` | Gato Rajado (Bagunceiro) |

## Gatos especiais
| Arquivo | Gato |
|---|---|
| `ninja.png` | Ninja Cat |
| `sleepy.png` | Sleepy Cat |
| `magician.png` | Magician Cat |
| `angry.png` | Angry Cat |
| `lucky.png` | Lucky Black Cat |

## Dicas
- Formato **PNG com fundo transparente**.
- Quadradas (ex.: 256×256 ou 512×512), o jogo recorta/ajusta sozinho.
- Mantenha o gato centralizado, com uma margem pequena nas bordas.
